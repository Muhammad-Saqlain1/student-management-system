STUDENT MANAGEMENT SYSTEM

Technologies:
HTML, JavaScript, Node.js, Express.js

How to run:

1. Install Node.js.
2. Open this project folder in VS Code.
3. Open Terminal.
4. Run:
   npm install
5. Run:
   node server.js
6. Open browser:
   http://localhost:3000

Features:
- Add student
- View students
- Search student
- Edit student
- Delete student
- REST API with GET, POST, PUT and DELETE

Important:
Do not open public/index.html directly.
Run the Node.js server first and open http://localhost:3000.

Note:
Student data is stored temporarily in server memory. It will reset when the server restarts.
